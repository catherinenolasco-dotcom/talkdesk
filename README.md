# Catherine Nolasco Portfolio

A static, single-page virtual portfolio for the Head of People Operations and Rewards role, styled after the Talkdesk brand. It is independent and not affiliated with or endorsed by Talkdesk.

people ops. powered by AI.

## View it

Open `index.html` in a browser, or publish it with GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder). Fonts are embedded, so the page has no external dependencies and no JavaScript.

## Files

- `index.html` is the finished portfolio.
- `Catherine Nolasco_Resume_Head of People Operations and Rewards_09232026.pdf` is the matching 2-page ATS-friendly resume.
- `src/content.py` holds all page and resume content.
- `src/build_portfolio.py` and `src/build_resume.py` regenerate the portfolio and resume. They expect the `@fontsource/outfit` and `@fontsource/figtree` npm packages in a local `node_modules` folder and Playwright with Chromium for the PDF.
